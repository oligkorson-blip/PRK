> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Polish every Parkwise page while preserving the current brand, content, structure, URLs, data, and functional flows.

**Architecture:** Keep the static HTML/CSS/JavaScript architecture. Centralize visual changes in `css/style.css`, make shared navigation and accessibility behavior changes in `js/main.js`, and avoid page-specific markup edits unless browser verification proves they are necessary.

**Tech Stack:** HTML5, CSS custom properties and media queries, ES5-compatible browser JavaScript, Python static HTTP server for local verification.

- Preserve the green, cream, lime, mint, and orange palette.
- Preserve Archivo, Inter, and Fraunces typography.
- Preserve all copy, catalogue data, illustrations, page order, URLs, registration steps, and demo behavior.
- Add no dependencies, frameworks, build tools, backend services, analytics, or generated assets.
- Maintain visible keyboard focus, readable contrast, and reduced-motion support.
- Target approximately 360px, 768px, 1024px, and 1440px viewport widths.
- Keep practical interactive targets at least 44px high.
- This directory has no Git metadata; skip commit steps and retain changes directly in the workspace.

- [ ] **Step 1: Replace the mobile-navigation behavior**

Replace the current mobile navigation block in `js/main.js` with:

```js
  /* ---------- mobile nav ---------- */
  var header = document.querySelector(".site-header");
  var toggle = document.querySelector(".nav-toggle");
  if (header && toggle) {
    function setMenu(open) {
      header.classList.toggle("menu-open", open);
      toggle.setAttribute("aria-expanded", open ? "true" : "false");
      toggle.setAttribute("aria-label", open ? "Close menu" : "Open menu");
    }

    toggle.setAttribute("aria-expanded", "false");
    toggle.setAttribute("aria-haspopup", "true");

    toggle.addEventListener("click", function () {
      setMenu(!header.classList.contains("menu-open"));
    });

    header.querySelectorAll(".nav-links a, .nav-actions a").forEach(function (link) {
      link.addEventListener("click", function () {
        setMenu(false);
      });
    });

    document.addEventListener("keydown", function (event) {
      if (event.key === "Escape" && header.classList.contains("menu-open")) {
        setMenu(false);
        toggle.focus();
      }
    });

    document.addEventListener("click", function (event) {
      if (header.classList.contains("menu-open") && !header.contains(event.target)) {
        setMenu(false);
      }
    });
  }
```
